# 项目概览

## 项目目标与阶段

Astral Flow 是全屏、安静的长曝光星轨交互作品。按住屏幕、鼠标左键、Space 或 Enter 时，各星体沿独立圆周运动并积累细弧；松开后约 1.05 秒消散，背景星点、标题和中心圆环保留。目标以 [prompt_01.txt](../../prompt/prompt_01.txt) 为准；当前实现见 [StarfieldScene](../../src/components/StarfieldScene.tsx) 与[渲染引擎](../../src/engine/StarTrailEngine.ts)。

第二轮已修复周期闪烁：每帧统一从有限历史绘制，释放冻结完整动态画面并用单曲线淡出。依据 [prompt_02.txt](../../prompt/prompt_02.txt)，保留已有构图与交互，并将桌面粒子调为 360。新录屏全部 256 帧已量测、全帧总览已复核；固定时序下 46 秒连续采样、原生时间 46 秒性能与 16 项浏览器验收已完成，详见[闪烁报告](../../docs/flicker-analysis.html)。
