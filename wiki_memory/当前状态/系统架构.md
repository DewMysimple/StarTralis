# 系统架构

## 模块职责与边界

| 模块 | 职责与边界 |
| --- | --- |
| [StarfieldScene](../../src/components/StarfieldScene.tsx) | DOM、双可见 Canvas、标题和圆环；Pointer Capture、键盘集合、多输入合并、ResizeObserver、失焦/隐藏释放及清理。逐帧计算不进入 React state。 |
| [StarTrailEngine](../../src/engine/StarTrailEngine.ts) | 创建粒子、时间积分、轨迹历史、画布合成、消散、DPR 与 RAF 管理。输入只有按压状态、尺寸和 reduced-motion。 |
| [StarParticle](../../src/engine/StarParticle.ts) | 独立半径、角度、角速度、亮度、线宽、激活延迟及寿命；每星 384 槽 TypedArray 保存约 30 Hz 的真实历史。 |
| [global.css](../../src/styles/global.css) | 深蓝黑背景、暗角、衬线字体、固定圆环、手机断点和无滚动全屏布局。 |
| [分析脚本](../../scripts/analyze_reference.py)与 [docs](../../docs/reference-analysis.html) | 独立研究工具与报告，读取本地原片，不参与产品运行。 |
| [浏览器测试](../../tests/starfield.spec.ts)与[录制脚本](../../scripts/capture-preview.mjs) | 验收与证据生成，不作为网页运行依赖。 |

关键分层和有限历史的采用者、取舍与实现状态保存在[ADR-001](../决策/ADR-001-分层画布与有限历史星轨.md)。

## 数据流与依赖

输入事件 → `syncInput()` 合并鼠标/触摸与键盘 → `engine.setPressed()` → `idle / pressing / releasing`。按住时单一 RAF 用秒级真实 `dt`（上限 0.05）推进独立角度，约 0.34 秒平滑启动，2.7 秒内分批激活。释放立即停止运动和新轨迹，约 1.05 秒淡出后清空动态层并停止 RAF；页面隐藏也停止并清回 idle。[来源：场景与引擎]

静态背景 Canvas 仅在初始化/尺寸变化时重绘；离屏 history Canvas 累积运动弧并以 `destination-out` 衰减；显示 Canvas 叠加 history 和即时星头。每 0.45 秒从有限历史重建弧线，避免 8-bit alpha 舍入导致长按后残留成整圈。辉光纹理缓存；轨迹寿命为 3.2–10.2 秒。[来源：引擎与粒子]

桌面初始 480 动态星、手机 280；低性能提示下降为 360/240，reduced-motion 为 180 且速度 20%。DPR 上限为桌面 2、手机 1.75、低性能 1.25，另有像素预算和持续慢帧降量。中心坐标与 CSS 圆环一致：横向 50%，桌面纵向 67%、宽度 ≤600px 时 65%。修改断点或中心时须同时核对引擎与 CSS。

运行依赖仅 React / React DOM；开发依赖 Vite、TypeScript、React 插件和 Playwright，准确版本由锁文件确定。无后端、数据库、远程 API 或动画库。分析脚本另需 Python 的 OpenCV、NumPy、Pillow；项目内记忆工具只用 Python 标准库。

## 运行与部署

在根目录运行 `npm ci`、`npm run dev`，默认开发地址 `http://127.0.0.1:5180/`；端口严格固定，冲突时先核对进程。`npm run build` 做 TypeScript 检查并输出 `dist/`，`npm run preview` 默认 `http://127.0.0.1:4173/`。命令来自 [package.json](../../package.json) 与 [Vite 配置](../../vite.config.ts)。

`npm test` 启动或复用 5180 上的服务器，使用 Chromium；缺浏览器时先 `npx playwright install chromium`。`npm run capture:preview` 要求开发服务器已启动，写入 `docs/verification/`。分析报告通过开发服务器 `/docs/reference-analysis.html` 或本地文件打开；原片、报告和验收素材不进入 `dist/`。

同日已有记录证明生产构建与本机 production preview 验证通过；尚无托管平台配置或云端部署验收。GitHub 仓库用于版本管理，不能等同于网站已发布。
