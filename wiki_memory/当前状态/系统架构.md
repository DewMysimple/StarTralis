# 系统架构

## 模块职责与边界

| 模块 | 职责与边界 |
| --- | --- |
| [StarfieldScene](../../src/components/StarfieldScene.tsx) | DOM、双可见 Canvas、标题和圆环；Pointer Capture、键盘集合、多输入合并、ResizeObserver、失焦/隐藏释放及清理。逐帧计算不进入 React state。 |
| [StarTrailEngine](../../src/engine/StarTrailEngine.ts) | 创建粒子、时间积分、轨迹历史、画布合成、消散、DPR 与 RAF 管理。输入只有按压状态、尺寸和 reduced-motion。 |
| [StarParticle](../../src/engine/StarParticle.ts) | 独立半径、角度、角速度、亮度、线宽、激活延迟及寿命；每星 384 槽 TypedArray 保存约 30 Hz 的真实历史。 |
| [global.css](../../src/styles/global.css) | 深蓝黑背景、暗角、衬线字体、固定圆环、手机断点和无滚动全屏布局。 |
| [分析脚本](../../scripts/analyze_reference.py)与 [docs](../../docs/reference-analysis.html) | 独立研究工具与报告，读取本地原片，不参与产品运行。 |
| [浏览器测试](../../tests/starfield.spec.ts)与[录制脚本](../../scripts/capture-preview.mjs) | 验收与证据生成，不作为网页运行依赖。 |

现行统一历史渲染、释放与续按的选择及代价保存在 [ADR-002](../决策/ADR-002-统一历史渲染与冻结淡出.md)；初版周期重建决策 ADR-001 已被替代，保留为历史。

## 数据流与依赖

输入事件 → `syncInput()` 合并鼠标/触摸与键盘 → `engine.setPressed()` → `idle / pressing / releasing`。按住时单一 RAF 用秒级真实 `dt`（上限 0.05）推进独立角度，约 0.34 秒平滑启动，2.7 秒内分批激活。释放立即停止运动和新轨迹，约 1.05 秒淡出后清空动态层并停止 RAF；页面隐藏也停止并清回 idle。[来源：场景与引擎]

静态背景 Canvas 仅在初始化/尺寸变化时重绘。显示 Canvas 每帧都按同一规则，从每星有限记录生成一条连续圆弧；历史曝光乘以 `exp(-0.22×age)` 及寿命边缘 smoothstep。路径延伸到实时角度，星头独立绘制。轨迹寿命仍为 3.2–10.2 秒，约 30 Hz 采样、每星 384 槽并剪除过期记录；RGBA 字符串表与辉光纹理缓存。[来源：引擎与粒子]

释放将完整显示画面复制到离屏 frozen Canvas，停止新增历史和角位移，仅按 `1-smoothstep(elapsed/1.05)` 整体淡出。独立运动时间只在 pressing 时推进；续按用最后显示强度缩放旧曝光，保留位置，端点与星头从该强度平滑恢复。没有增量/重建切换，也没有周期性像素擦除。

桌面初始 360 动态星、手机 240；低性能提示为 280/200，reduced-motion 为 160 且速度 20%。持续慢帧时逐步降低预算，受影响星体在 2 秒内淡出，避免整组跳失。DPR 上限为桌面 2、手机 1.75、低性能 1.25，另有像素预算。中心仍为横向 50%，桌面纵向 67%、宽度 ≤600px 时 65%，须与 CSS 同步。

运行依赖仅 React / React DOM；开发依赖 Vite、TypeScript、React 插件和 Playwright，准确版本由锁文件确定。无后端、数据库、远程 API 或动画库。分析脚本另需 Python 的 OpenCV、NumPy、Pillow、Matplotlib；项目内记忆工具只用 Python 标准库。

## 运行与部署

在根目录运行 `npm ci`、`npm run dev`，默认开发地址 `http://127.0.0.1:5180/`；端口严格固定，冲突时先核对进程。`npm run build` 做 TypeScript 检查并输出 `dist/`，`npm run preview` 默认 `http://127.0.0.1:4173/`。命令来自 [package.json](../../package.json) 与 [Vite 配置](../../vite.config.ts)。

`npm test` 启动或复用 5180 上的服务器，使用 Chromium；缺浏览器时先 `npx playwright install chromium`。`npm run capture:preview` 写入 `docs/verification/`。`npm run measure:stability` 连续受控采样，`npm run benchmark:stability` 做 46 秒原生时间测量，`npm run report:stability` 生成曲线与报告数据，均需先启动开发服务。报告入口为 `/docs/reference-analysis.html` 与 `/docs/flicker-analysis.html`；研究资料不进入 `dist/`。

同日已有记录证明生产构建与本机 production preview 验证通过；尚无托管平台配置或云端部署验收。GitHub 仓库用于版本管理，不能等同于网站已发布。

## 证据与未核实项

2026-10-31 基于 `1b1db04` 加本地第二轮实现验证；Windows / Node.js 24.16.0 / Chromium 156。生产构建通过，16 项浏览器测试通过；960×600、DPR=1、60 Hz 的 46 秒连续采样三个窗口均无超过 5% 的骤降。另有 144 Hz、高 DPR 连续测试与 1440×900 原生时间 46 秒测量，详见[本轮摘要](../../docs/verification/iteration-02/summary.json)。

现代 Chromium 已有验证；其他浏览器对 `createConicGradient`、指针捕获和移动视口的实际表现待实测。帧间隔记录是本机无头浏览器观测，不能证明所有设备性能。
