# 当前约束

## 用户要求与技术约束

- 用户指定 `standard` 工程记忆，固定根目录 `wiki_memory/`，保留五页有效状态和六类日志目录；模式不得因项目较小自行降级。依据为本轮明确指令，维护工具与协议版本为 3.2.1。
- 用户持续要求：以后每一次完整对话产生的项目修改都提交并推送到 `https://github.com/DewMysimple/StarTralis.git`。有效执行规则在[根 AGENTS.md](../../AGENTS.md)，常规交付已获授权，无需重复确认。
- 产品要求来自 [prompt_01.txt](../../prompt/prompt_01.txt)：React + Vite + TypeScript + Canvas 2D；所有星点和星轨实时生成，保持深蓝黑、银白细弧、克制辉光与暗部留白。只保留标题、副标题、星空、星轨和中心圆环，不添加无关 UI。
- 固定标题 `Astral Flow`、副标题 `Following the silent movement of distant stars.`；轨道中心为横向 50%、桌面纵向 67%、手机 65%，不跟随按压点。视频的标题轮换和自动时间线不作为网页行为。
- 按住约 6–8 秒应形成丰富弧线；松开立即停止新运动和轨迹，约 0.8–1.2 秒自然消散，当前实现为 1.05 秒。背景、文字和圆环保留。必须支持鼠标、触摸、键盘、失焦/取消、连续按压和尺寸变化。
- 单一 RAF、真实时间积分、静态背景独立、DPR 限制、缓存辉光、固定容量历史与卸载清理；逐帧数据不写 React state。当前选择和实现边界见[系统架构](系统架构.md)。

## 兼容性与操作边界

指定视觉验收尺寸为 1440×900、1920×1080、390×844、768×1024。Chromium 的受控浏览器测试、CDP 触摸和 DPR 模拟已经有记录；不把模拟结果表述为实物手机、Safari 或 Firefox 验收。尊重 `prefers-reduced-motion`。Node.js 安装与运行要求见 [README.txt](../../README.txt)。

现有工程在原目录维护；不覆盖无关文件、不删除原始参考素材、不强制推送或破坏性重置远程。提交前核实实际分支和远程，只提交本轮相关变更；保留其他任务改动。默认交付 `main`。只读对话无项目修改时不制造空提交。

授权包括本项目源码、参考分析、配置和必要工程记忆的 GitHub 版本管理。依赖、`dist/`、测试临时目录及本地秘密文件按 [.gitignore](../../.gitignore) 排除。没有额外的部署、域名、其他项目 Git 或对外发消息授权；GitHub 推送本身不代表网站已部署。
