# ADR-001：分层画布与有限历史星轨

2026-10-31 被 [ADR-002](ADR-002-统一历史渲染与冻结淡出.md) 替代：保留分层与有限记录，移除周期重建和增量叠加的双模型。下文为初版选择及当时证据，不代表当前实现。

## 背景与授权

用户要求 Canvas 2D 实时生成独立运动的星体，按住累积、松开自然消散，背景星点始终保留，长按 46 秒仍像长曝光而非完整科技圆环。[需求来源](../../prompt/prompt_01.txt)

在该授权范围内，由开发 Agent 采用下述常规渲染方案；用户指定的是产品行为与技术栈，分层和历史容量属于实现选择。本页于首次版本管理时根据已实现源码回填，不代表新增一次用户确认。

## 选择与实施状态

已实施：两个可见 Canvas 分别保存静态背景和动态显示，离屏 Canvas 保存轨迹历史。引擎单一 RAF 以真实时间推进每颗星的角度，轨迹做指数擦除，星头与缓存辉光单独合成，避免辉光永久烙入轨迹。[引擎](../../src/engine/StarTrailEngine.ts)

每颗星以 384 槽 TypedArray 记录约 30 Hz 的真实角度/时间/曝光；每 0.45 秒根据有效寿命重建一次连续有限圆弧，并用 conic gradient 表达沿时间的透明度变化。它修正 8-bit alpha 舍入累积；绘制范围来自真实运动历史，不预先生成完整圆环。[粒子](../../src/engine/StarParticle.ts)

释放立即停止运动与新增轨迹，1.05 秒内淡出并停 RAF；未完全淡出时重新按住，按当前可见强度衰减旧历史后继续。尺寸变化重配 backing store 和轨道，不拉伸旧画布。

## 理由与代价

分层使背景不会随轨迹淡出，星头可比尾迹更亮；固定容量使长按内存有界。真实历史重建消除整圈残留及分段透明度接缝。代价是多份画布缓冲和周期性重建成本，因此同时限制 DPR、像素预算和粒子数；conic gradient 的目标浏览器仍需实测。

当前项目没有选择 WebGL、Three.js、现成视频背景或复杂动画依赖。改成这些技术属于后续方案调整，不能因某项历史测试通过自行改变用户指定的 Canvas 2D 约束。

## 验证线索与限制

[浏览器用例](../../tests/starfield.spec.ts)覆盖累积、46 秒长按、衰减中续按、完整释放、四种尺寸与刷新率时间积分；[已有验收记录](../../docs/verification/verification.txt)保存建仓前执行结果。本次只核对源码与历史证据，没有为记忆回填重跑业务测试。

核实日期 2026-10-30，Windows / Node.js 24.16.0，首次 Git 提交前本地业务实现。物理设备性能、Safari / Firefox 兼容不在已有验证覆盖内；详见[已知问题](../当前状态/已知问题.md)。
