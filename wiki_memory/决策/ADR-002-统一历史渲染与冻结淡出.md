# ADR-002：统一历史渲染与冻结淡出

## 背景、选择者与授权

用户在第二轮明确要求修复周期闪烁，首选有限历史驱动的确定性渲染；保持 Canvas 2D、构图、独立运动与交互，不使用未经验证的交叉淡入补丁。Agent 在此授权内实施以下方案。

旧版 `1b1db04` 的同一次重建调用前后约有 15%–19% 轨迹能量差，连续采样在 3–8 秒出现 11 次超过 5% 的下降。初版通过固定时点验收无法证明时间连续性，因此替代 ADR-001 中周期重建部分。

## 已采用与实施状态

已实施：每一帧用同一套有限历史生成完整开放弧，透明度只由样本曝光、年龄指数衰减和寿命边缘决定。路径连接到实时角度，旧记录按寿命剪除；每星保留 384 槽，RGBA 字符串与辉光资源缓存，不存在持久像素尾迹的量化残留。

释放复制完整可见画面，以单一 1.05 秒 smoothstep 曲线淡出。运动时间在释放期间暂停；续按把旧记录和端点缩放到最后可见强度，再连续恢复新运动。此离屏画面只服务冻结淡出，不是周期性双缓冲交叉混合。

桌面选用 360 星、手机 240 星；普通星更暗、少数星突出。该视觉参数由 Agent 在用户允许的 320–400 范围内通过效果和帧耗时选择，未改变轨道圆心、速度范围、排版与输入。

## 代价与控制

每帧生成渐变和有限弧比增量绘制增加 Canvas 调用。用每星单次连续描边、约 0.2 秒间隔的渐变控制点、缓存颜色表、有限样本、DPR 上限和缓慢质量退出来控制代价。原生测量的绘制回调耗时仅反映本机 JS/Canvas 调用，不等价完整 GPU 呈现或跨设备 FPS 保证。

## 验证与范围

2026-10-31，`main@1b1db04` 加本轮本地实现，Windows / Chromium 156：生产构建、16 项浏览器用例通过。受控 60 Hz 的 3–8 / 12–20 / 36–46 秒最大单帧下降约 0.47% / 0.50% / 0.46%，均无超过 5% 的骤降；高 DPR 144 Hz 窗口最大约 0.35%。六次快速续按最大变化约 2.35%。

真实时间 46 秒的 3–46 秒稳态绘制回调 P95 3.6 ms，三个检查点均为 360 条轨迹、无质量降量；释放后 alpha=0、错误为空。原始记录、统计环境和截图排除规则见[摘要](../../docs/verification/iteration-02/summary.json)。实物手机、Safari / Firefox 仍待验收。
